url: "https://github.com/sepraca/Mie_phase_matrix_code"
private: true
---
A validated pipeline for computing Mie-scattering optical properties of liquid water cloud droplets. Provides the full phase matrix, asymmetry parameter, single-scattering albedo, and extinction efficiency. User can select monochromatic or MODIS/VIIRS bandpasses, with size distribution and bandpass integration algorithms identical to standard NASA MODIS (MOD06/MYD06) and VIIRS (CLDPROP) LUTs.

Polarization-Capable Interactive 3D Monte Carlo Cloud-Lidar Simulator, based on the VISTA-C code package. Provides full-Stokes (I, Q, U, V) with an interactive, range-resolved Monte Carlo simulator of elastic monostatic lidar observations from three-dimensional cloud slabs.
